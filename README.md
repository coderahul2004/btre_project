# Real Estate Listing Platform

A full stack Real Estate web application built using Django, mysql, HTML, CSS, and JavaScript.

The platform allows users to browse property listings, search/filter properties, and send inquiries to realtors.

---

## Features

* Property listing management
* Realtor profiles
* Property search and filtering
* User authentication
* Inquiry/contact system
* Admin dashboard
* Responsive frontend UI

---

## Tech Stack

### Backend

* Django
* MYSQl

### Frontend

* HTML
* CSS
* JavaScript
* Bootstrap

---

## Database Models

* Listings
* Realtors
* Users
* Contacts/Inquiries

## Installation

### Clone Repository

```bash
git clone https://github.com/coderahul2004/btre_project.git
cd btre_project
```

### Create Virtual Environment

```bash
python -m venv env
```

### Activate Environment

#### Windows

```bash
env\\Scripts\\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Server

```bash
python manage.py runserver
```
